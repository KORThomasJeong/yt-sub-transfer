진짜로 무료입니다.

YouTube 구독을 옮겨 준다는 확장 프로그램 중에 결제를 유도하거나 이상한 권한을 요구하는 것들이 하도 많아서, Claude Code로 직접 만들었어요.
푼돈 받고 싶지도 않고, 광고도 없고, 서버도 없습니다. 그냥 마음껏 쓰세요.

■ 할 수 있는 일
• 내보내기: 지금 계정의 모든 구독 채널을 JSON 또는 CSV 파일로 저장
• 가져오기: 저장한 파일로 다른 계정에 같은 채널들을 한 번에 구독
• 이미 구독 중인 채널은 알아서 건너뜀
• 끝나면 YouTube에 실제로 구독됐는지 다시 확인하고, 실패한 채널은 CSV로 받을 수 있음
• Google Takeout의 subscriptions.csv, NewPipe·FreeTube 백업 파일도 가져올 수 있음
• CSV는 Google Takeout과 같은 형식이라 FreeTube·NewPipe 같은 다른 앱에서도 그대로 사용 가능

■ 사용법
1. 원래 계정으로 로그인한 YouTube 탭에서 확장 아이콘 → "JSON 내보내기"
2. 옮길 계정으로 전환
3. 확장 아이콘 → 파일 선택 → "가져오기 시작"
   (팝업을 닫아도 계속 진행됩니다. 탭만 닫지 마세요.)

■ 안심하고 쓰셔도 되는 이유
• 모든 처리는 내 브라우저 안에서만 이루어집니다
• youtube.com 외에는 아무 데도 연결하지 않습니다
• 개인정보, 비밀번호, 쿠키를 수집하거나 보내지 않습니다
• 회원가입, 결제, API 키 같은 것 전혀 필요 없습니다
• 권한은 youtube.com 접근 하나뿐입니다
• 소스코드 공개(MIT): https://github.com/KORThomasJeong/yt-sub-transfer

■ 참고
• 구독할 채널이 수백 개면 YouTube가 속도를 제한할 수 있습니다. 실패가 많으면 대기 시간을 3~5초로 늘리고 같은 파일로 한 번 더 돌리세요. 이미 구독된 채널은 건너뜁니다.

이 확장은 YouTube 또는 Google과 관련이 없는 비공식 도구입니다.
